> **Audience**: Emergency exam cramming suite optimized for neurodivergent and ADHD learners with high pre-exam anxiety.

## 🌟 Quick Start Options

### Option 1: Zero-Setup Interactive Browser Station (Instant Access)
* Simply double-click `index.html` (or open `dist/index.html` in Chrome, Brave, Safari, or Edge).
* Works **100% offline** with zero terminal installation.
* Features:
  - **Act 1: Feynman Storyboards**: 8 narrative concept cards with text-to-speech audio briefs.
  - **Act 2: The 50-Mark Essay Architect**: 4 guaranteed exam essay models with Examiner's Red Pen (4/20 vs 18/20) and 1-click **"Copy Formatted for Word"**.
  - **Act 3: Active Recall Radar**: 8 high-yield MCQs with instant feedback, streak bonuses, and trap explanations.
  - **Act 4: 1-Page Exam Hall Brain-Dump Sheet**: The 4 core memory acronyms (M-O-N-O, T-P-G-I, B-M-V-N-C, P-P-S-M-S) for the 60-second scrap paper protocol.

---

### Option 2: Autonomous OpenCode Guided Agent Session
Open this directory in your terminal or IDE using OpenCode:

```bash
opencode
```

Paste the contents of **`GIRLFRIEND_PROMPT.md`** into your chat prompt. The agent will adopt the **Compassionate Socratic Mentor** identity:
* Never sends walls of text.
* Uses the 3-Step Socratic Loop: *(1) Story Hook $\to$ (2) UP Examiner Keywords $\to$ (3) Single Micro-Recall Question*.
* Permissively accepts messy, half-finished bullet points or voice-to-text.
